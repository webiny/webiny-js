# src-static

This folder contains static files that should persist across package regenerations.

## Purpose

The `webiny` package's `src` folder is automatically generated by running the `generate-webiny-package` script. During generation, the `src` directory is completely deleted and recreated.

To preserve certain files that should not be deleted, they are stored in this `src-static` folder. During the generation process, all contents of `src-static` are automatically copied to `src` after cleanup.

## Files

- `global.d.ts` - Global type augmentations for Webiny
- `global.ts` - Global imports for Webiny
- `configs/tsconfig.json` - TypeScript configuration for the configs folder

## Adding New Static Files

To add new static files that should be preserved:

1. Add the file(s) to this `src-static` folder in the appropriate subdirectory structure
2. Run the generation script - the files will be copied to `src` automatically
