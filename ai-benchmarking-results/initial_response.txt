
   Issues Identified

   🔴 Critical Issues

     - Copy-paste error in encrypt function (line 34)
       - Error message says "Cannot call decrypt" but should say "Cannot call encrypt"
       - Impact: Confusing error messages, poor debugging experience
     - Silent failure on encryption/decryption errors (lines 25-27, 41-43)
       - Errors are logged to console but function returns empty string
       - Callers have no way to know if operation failed
       - Impact: Data loss, security vulnerabilities, hard to debug
     - Poor error logging (lines 21, 26, 42)
       - Uses console.log instead of proper logging framework
       - No structured logging or error context
       - Impact: Difficult monitoring, troubleshooting in production

   🟡 Reliability Issues

     - Inconsistent return behavior
       - Empty string returned for null values, decryption failures, and encryption failures
       - No way to distinguish between legitimate empty password vs error state
       - Impact: Ambiguous behavior, potential security issues
     - Missing error information in catch blocks (lines 25, 41)
       - Caught errors are ignored completely
       - No error details logged or propagated
       - Impact: Impossible to debug what went wrong
     - Weak type safety
       - Params interface allows null/undefined values but functions don't handle all edge cases consistently
       - Impact: Runtime errors, unclear contracts

   🔵 Maintainability Issues

     - Code duplication
       - Both functions share similar validation and error handling patterns
       - Could be extracted to reduce duplication
       - Impact: Harder to maintain, update, and test
     - Unclear empty string handling (lines 14-16, 36-38)
       - Not clear if empty string is a valid password or should be treated as null
       - Impact: Unclear business logic
     - No input validation
       - Secret length/format not validated
       - Value encoding not validated
       - Impact: Potential security issues
     - Missing JSDoc comments
       - No documentation on function purpose, parameters, return values, or error conditions
       - Impact: Poor developer experience
