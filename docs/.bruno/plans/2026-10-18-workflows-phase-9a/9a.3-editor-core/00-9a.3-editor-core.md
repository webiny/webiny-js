**Goal:** Everything the editor shares and that knows no app, then the two app gateways. In `packages/app-workflows/src/editor`: domain types, the workflow error codes, DTOs and GraphQL selections, mappers (`savedOn` is a string and never changes on the way), the editor gateway and use-case interfaces with the one shared `WorkflowEditorUseCases` (plain class, subclassed per app), the shared config gateway and use cases (`workflows` root: step types, automation definitions, notification transports, `listTeams`, AI models and tools), the editor toasts, `WorkflowEditorServicesFeature` registered in `WorkflowsAdminApp`, and the R243 fixtures and fakes. Then `ReviewUseCases.invalidateWorkflows()` (R277). Then the CMS and WB gateways, their GraphQL documents, their one-line use-case subclasses and their features, registered from each package root.

**Depends on:** 9a.1 for the SDL the documents select (`workflows.listTeams` (Task 2), `WorkflowsAiTool.changesContent` (Task 2b) and the unchanged `listCmsEntryWorkflowModels`, `getCmsEntryWorkflow`, `storeCmsEntryWorkflow`, `deleteCmsEntryWorkflow` and the WB page equivalents).
