## Review Focus for this sub-phase

Review Focus 9. The root cause is pinned: `makeAutoObservable(this)` deep-converts the presenter's `params` (and the `item` / `items` it builds), and a React element created during a render points at its owner fiber, which is a cycle. The fix must make the three presenters keep those fields by reference (`observableRef`, the annotation name in mobx 7) and nothing else; `vm` stays a computed, `init` and the handlers stay actions. Check the fix does not change what any existing admin-ui test asserts, that each component has a JSX-label regression test that fails without the fix, and that the app-workflows renderer tests are the unchanged behaviour spec for commit 2. `RadioGroupRenderer` forwarding `aria-label` and `aria-labelledby` is the only behaviour added.
