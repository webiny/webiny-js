## Review Focus for this sub-phase

From `../00-shared.md` Review Focus: items 1 (every action without target read access, request without write access), 2 (cancel by a non-requester without `reassign`; finished review reports the engine's state error, also for a `reassign` holder), 8 (D115 listing, interleaved test, 50-check cap), 9 (cross-app), 10 (cancel-for-delete: delete access, no cancel right, reason recorded). Each wrapper must call `CurrentReviewViewer` before anything else, never call an engine use case before its checks pass, and never turn an engine state error into "not authorized" (1b R41). The store and delete tests assert `payload.actor` on the workflow events (R80). The API-key tests (Task 14) use a real stored key and its token through api-core's `ApiKeyAuthenticator` (R79), and the pool-step refusal acts on a review someone else requested.
